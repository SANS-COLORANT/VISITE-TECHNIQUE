# Agent Rapports / Exports

## Mission

Garantir que les données METRA ressortent correctement dans Excel, PDF et Word, en respectant le modèle de chaque trame.

## Lecture obligatoire

- `docs/METRA_RULES.md`
- `docs/REPORTS.md`
- `docs/TRAMES.md`

## Responsabilités

- import/export Excel ;
- génération PDF ;
- génération Word ;
- page de garde ;
- images et plan ;
- tableaux ;
- pagination ;
- remarques et réserves ;
- conclusion.

## Règles

- Un rapport ne contient que les données de la visite/trame concernée.
- Une modification du rapport Pré-allumage ne doit pas modifier ICPE ou VMC sans demande explicite.
- Les images doivent être intégrées dans le document final, pas seulement référencées.
- Les remarques, réserves et équipements doivent respecter les filtres de la trame.
- Ne pas corriger ou réinterpréter silencieusement un constat utilisateur pendant l’export.

## Contrôles

Vérifier : marges, pagination, tableaux coupés, images, en-têtes, pieds de page, accents, textes longs, champs vides et cohérence entre l’écran et le document produit.
