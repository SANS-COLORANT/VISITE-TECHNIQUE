# METRA — Rapports et exports

## Formats

METRA peut produire selon la trame :
- Excel ;
- PDF ;
- Word.

## Principe d’isolation

Un rapport utilise uniquement les données de la visite sélectionnée et de sa trame.

Aucune remarque ICPE ne doit apparaître dans un rapport VMC ou Pré-allumage, et inversement.

Les équipements affichés doivent être ceux applicables à la trame concernée.

## Pré-allumage

Le rendu PDF/Word cible suit le compte-rendu de référence Energie & Service :
- page de garde ;
- intervenants ;
- plan du site et informations bâtiments ;
- relevés compteurs ;
- régulation et températures ;
- essais chaufferie ;
- essais sous-stations ;
- observations, réserves et conclusion.

Le plan du site est une donnée patrimoniale sélectionnable dans l’application et réutilisable d’une visite à l’autre.

## Contrôles qualité

Avant validation d’un changement de rapport, vérifier :
- présence des images ;
- proportions et résolution ;
- pagination ;
- tableaux non coupés de manière incohérente ;
- longues remarques ;
- caractères accentués ;
- en-têtes et pieds de page ;
- cohérence des cellules vides ;
- séparation stricte des trames ;
- cohérence entre données écran et données exportées.
